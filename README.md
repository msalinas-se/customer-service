# customer-service

Microservicio que maneja la información de los clientes de un banco.

Los clientes del banco son de dos tipos: personal o empresarial.

Perfiles adicionales: VIP para clientes personales y PYME para clientes empresariales.

Los clientes se guardan en caché con Redis.

## Tecnologías

- Java 17
- Spring Boot
- Spring Cloud (Config, Eureka, Resilience4j)
- RxJava
- Redis
- Maven
- MongoDB
- Lombok
- Logback
- JUnit, Mockito y JaCoCo
- Docker
